# Public recruitment scope and security boundaries

This repository is a **separate public volunteer-recruitment and synthetic-screening venue**. It is **not** the KAITO trading source repository, an exchange gateway, a place to submit credentials, or a verified independent audit.

## We are looking for

- **Independent methodological reviewer #1 and #2:** Python numerical/statistical tests, backtest data leakage, overfitting, loss clustering and tail risks, chronological equity/cashflow accounting, transaction fees/slippage/funding, negative controls and risk decisions.
- **Independent CI witness #3:** Verifiable exact Git commit, GitHub Actions workflow attempts, executed steps, artifact hashes, and independent source-bound provenance checks.

These roles must be controlled by genuinely distinct parties. Separate usernames or signatures generated by one operator **do not** create independence.

## Participation

- Volunteer and **unpaid**. Initial request is an optional **20–30-minute scoping conversation** or equivalent short written exchange; any substantive review must be separately agreed. No employment contract, consulting fee, referral, token reward, revenue share, trading signals or performance guarantee is offered.
- We welcome skeptical findings and an explicit **HOLD** or **REJECT**. Never sign an approval without independent technical evidence.
- Applications should be made only in public GitHub issue comments, using a public GitHub handle, role, experience and optional public work examples. Do **not** ask for or publish private personal details.

## What access is *not* given

- No Bitget or other exchange account, API key or passphrase, seed phrase, passwords, OTP, bank/payment credentials, transaction authority, transfer or withdrawal authority.
- No Railway secrets, production infrastructure access or tokens.
- No direct collaborator/write access to the personal-account-owned **private** trading source repository. The private trading repository remains private.
- No authentic trade records or private source code is distributed in the public recruitment stage. A synthetic answer does **not** qualify a reviewer to approve the actual method.
- Any future access to specific privately hosted evidence will require a separate, Owner-approved **least-privilege read-only** access mechanism. No permission is implied by applying.

## Evidence and release policy

Before the first new training or real-money actions, the private project's authentic governance requires two independent in-depth reviews, a third independent witness of actual CI provenance, methodology findings resolved with defensible evidence, and separate readiness/risk/security authorization. These steps have **not** been met. **There is no verified positive-expectancy strategy or authorized live trading.**

## Security reporting

Do not post discovered vulnerabilities, sensitive paths, tokens, or personal data as public comments. Stop and report non-sensitive details via a private channel set up by the repository Owner. This public venue is not an authorized penetration-testing target; no testing of private systems, exchanges or infrastructure is requested.
